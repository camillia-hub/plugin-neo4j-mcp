# Neo4j MCP

Queries a Neo4j graph database. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/neo4j-mcp

Installs from the Camillia hub as `neo4j-mcp-d909b0`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
